# Week 1 Project: UK Retail Revenue Pipeline

**Domain:** Retail  
**Dataset:** [UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii)  
**Language:** Pure Python (no Pandas or ML libraries)

## What it does
Reads 500K+ UK retail transactions, groups revenue by country,
classifies each as High/Medium/Low tier, and exports results.

## Key findings
- UK dominates with £X revenue across X orders
- X countries classified as High tier
- X orders were cancelled/invalid and excluded

## How to run
1. Download the dataset from the link above
2. Run: `week1_project_retail_pipeline.py`
3. Results appear in `retail_results.txt`
